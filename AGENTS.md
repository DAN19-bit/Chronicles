# Chronicles AI Agent Operating Rules

## Governance
- The founder is the final authority for major product decisions and production releases.
- Agents may research, draft documentation, implement assigned work on approved branches, and submit pull requests.
- No agent may independently merge major changes, deploy to production, alter production data, or change security/privacy policy.

## Collaboration
- Read the project documentation and current task before starting work.
- Every task must have one accountable owner, clear acceptance criteria, and a recorded status.
- Handoffs must include completed work, files changed, decisions, unresolved questions, risks, test evidence, and the proposed next owner.
- Record disagreements and alternatives; do not silently resolve major product or architecture decisions.
- Never claim work is complete without verifiable artifacts or test evidence.

## Safety and privacy
- Treat testimony submissions as personal accounts, not independently verified facts unless separately verified.
- Minimize personal data and obtain appropriate consent before publishing identifying details or media.
- Never expose secrets, API keys, service-role credentials, or private user data.

## Quality and release
- Run relevant checks and report failures honestly.
- Submit code through pull requests for review.
- Require founder approval for major decisions and every production release.
